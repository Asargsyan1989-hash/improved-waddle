# improved-waddle

Базовый репозиторий для будущего проекта. Назначение и технологический стек пока не выбраны; приложения, сборки и тестов продукта здесь ещё нет.

## Начало работы

```sh
git clone https://github.com/Asargsyan1989-hash/improved-waddle.git
cd improved-waddle
git switch -c feature/my-change
```

## Базовые файлы

- `.gitignore` — исключения для локальных секретов и временных файлов.
- `.editorconfig` — UTF-8, LF и единое форматирование.
- `.github/workflows/ci.yml` — проверка базовых файлов на push, pull request и при ручном запуске.

## CI

Workflow `Repository CI`, проверка `Repository checks`: наличие и непустое содержимое базовых файлов, UTF-8, LF, завершающий перевод строки и отсутствие пробелов в конце строк. Это проверка оформления репозитория, не тестирование приложения. После добавления кода нужно дополнить CI сборкой, линтером и тестами выбранного стека.

## Изменения и безопасность

Работайте в отдельной ветке и отправляйте pull request в `main`. Не публикуйте токены, пароли и `.env`; для CI используйте GitHub Actions Secrets. Защита `main` настраивается отдельно в Settings → Branches / Rules. Наличие этого README не означает, что защита включена.

Лицензия пока не выбрана; файл лицензии намеренно не добавлен.
