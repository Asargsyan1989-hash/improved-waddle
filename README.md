# improved-waddle

Базовый репозиторий для будущего проекта. Назначение и технологический стек пока не выбраны; приложения, сборки и тестов продукта здесь ещё нет.

## Начало работы

```sh
git clone https://github.com/Asargsyan1989-hash/improved-waddle.git
cd improved-waddle
git switch -c feature/my-change
```

## Базовые файлы

- `.gitignore` — исключения для локальных секретов и временных файлов.
- `.editorconfig` — UTF-8, LF и единое форматирование.
- `.github/ISSUE_TEMPLATE/bug_report.md` — шаблон сообщения об ошибке.
- `.github/ISSUE_TEMPLATE/feature_request.md` — шаблон предложения улучшения.
- `.github/pull_request_template.md` — описание изменений и чек-лист проверки.

## CI и защита ветки

На момент подготовки репозитория CI не настроен: файла workflow нет, автоматические проверки не запускаются. Защита `main` также не включена. Подключённый плагин позволяет редактировать обычные файлы, но попытка добавить workflow не сохранила файл; действия для настройки защиты ветки в плагине нет.

Следующие технические шаги после получения соответствующего доступа:

1. Добавить CI для проверки оформления базовых файлов.
2. Проверить фактический успешный запуск CI.
3. Защитить `main`: изменения через pull request, обязательная проверка CI, запрет force push и удаления ветки. Для работы в одиночку не требовать одобрения второго человека.
4. После добавления кода дополнить CI сборкой, линтером и тестами выбранного стека.

## Изменения и безопасность

Работайте в отдельной ветке и отправляйте pull request в `main`. Шаблоны задач доступны при создании issue; шаблон PR подставляется при создании pull request.

Не публикуйте токены, пароли и `.env`. `.gitignore` не защищает от уже добавленных в Git секретов. Для будущего CI используйте GitHub Actions Secrets.

Лицензия пока не выбрана; файл лицензии намеренно не добавлен.
